# Start Here

Career Radar is your private job recommendation and application tracker.

1. Configure the local `career_radar` database in `.env`.
2. Run `PYTHONPATH=src .venv/bin/python -m career_radar.cli setup`.
3. Start the dashboard with `PYTHONPATH=src .venv/bin/python -m career_radar.cli web`.
4. Use the private inbox import, candidate review queue and applications view to
   manage roles relevant to you.

The repository intentionally contains no public market archive or public
visualization.
